## 取り出し方（機械生成）

- 出典の HTML で、都道府県・指定都市の見出し（`<h2>`）のあとに、センターごとの行（`<tr class="cenN">` から次の `cenN` まで）が並んでいる。この並びどおりに取り出した。
- 名称は `<th>` の各行、所在地は `<td class="ad">` の各行、電話は `TEL` を含む行（`<td class="endCol">` の中）、URL は `<td class="url">` のリンク先。
- 文字の扱い：タグを除き、行ごとに前後の空白を詰め、ゼロ幅空白（U+200B）を除いた。それ以外の文字は変えていない（誤記と思われる字もそのまま）。
- evidence：各欄の原文の先頭 40 字まで。URL の evidence はリンクの文言。

## Claude Code の判断

| 項目 | 判断 |
|---|---|
| 指定都市の振り分け | 見出しに都道府県名があるもの（例「神奈川県・横浜市・川崎市・相模原市」）は、その都道府県に入れた（`pref_basis: heading`）。指定都市だけの見出し 8 件は、出典の並びで直前の都道府県に入れた（`pref_basis: preceding_heading`）：札幌市→北海道、仙台市→宮城県、千葉市→千葉県、浜松市→静岡県、堺市→大阪府、神戸市→兵庫県、岡山市→岡山県、北九州市→福岡県。どれも各市の属する都道府県と合っている |
| 電話の欄が無いセンター | 鹿児島県（1 件）は電話の欄が無く、所在地の欄の中に保健所ごとの電話が書かれている。電話の欄は作らず、所在地の欄の行をそのまま載せた。山口県も所在地の欄に地域のセンターの一覧がある（電話の欄は別にある） |
| URL が無いセンター | 4 件：千葉県「市原地域難病相談支援センター」、東京都「東京都多摩難病相談・支援室」「東京都難病ピア相談室」、福岡県「福岡県難病相談支援センター（北九州センター）」。キーごと入れていない |
| 名称が 2 行のもの | 埼玉県（運営団体名）、福岡県（福岡県と福岡市のセンター名の併記）、沖縄県（運営団体名）。出典の行のまま 2 行で出す |
| 出典の誤記と思われるもの | 山口県の所在地の欄の「荻市」「荻健康福祉センター」（萩市の誤記と思われる）。原文どおりにしている。直すかはファウンダー判断 |
| 画面の文 | 冒頭に出典と取得日。「受付の日時などは、各センターのページか出典でお確かめください」は運営の文（出典の文ではない）。末尾の「難病相談支援センターは、都道府県と指定都市に置かれています」は、出典の「都道府県及び指定都市に設置されています」を言い換えたもの |
| 都道府県の引き方 | 完全一致だけ（「大阪」では引かない）。見つからないときは案内を出し、全件を出す |
