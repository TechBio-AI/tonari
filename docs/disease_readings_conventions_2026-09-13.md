# 疾患名の読みの規約 — 2026-09-13

`data/disease_readings/readings.json` に読みを足すときの規約。読み込みは `lib/portal/disease-readings.ts`。

読みは疾患一覧を五十音に分けるためだけに使う。画面には出さない。
**読みは推定しない。** 出典を探し、見つからないものはファウンダーが判定する（2026-09-13 ファウンダー指示）。
形態素解析ライブラリは入れない。

## 根拠の順序

| level | 出典 |
|---|---|
| 1 | 難病情報センター（五十音別索引 https://www.nanbyou.or.jp/entry/5461 〜 5469） |
| 2 | 小児慢性特定疾病情報センター（疾患詳細ページ。一覧にふりがなは無く、1 疾患 1 ページの取得が要る） |
| 3 | 学会の用語集・機関誌 |
| 4 | Orphanet 日本語表記、GeneReviews 日本語版、J-STAGE の日本語論文 |
| 0 | 出典が見つからず、執筆者が付けた読み（source に、どこを確認したかと判定日を書く） |

読みは病名と違い、出典が無くても「存在しないものを作る」ことにはならない。
公的なふりがなが見つからない場合は、**執筆者による読み**として根拠レベル 0 のまま残してよい
（2026-09-13 ファウンダー判定）。**病名は違う。日本語名が無い疾患に日本語名を作ってはいけない**
（`data/disease_names/name_notes.json` と `docs/disease_name_rename_2026-09-13.md` を参照）。

readings.json は値を 2 通り書ける。根拠を残すときは後者。

```json
"軟骨無形成症": "なんこつむけいせいしょう",
"潰瘍性大腸炎": { "reading": "かいようせいだいちょうえん", "level": 1,
                  "source": "難病情報センター 五十音別索引 か行 https://www.nanbyou.or.jp/entry/5462" }
```

## 文字の扱い

出典は難病情報センターの指定難病 348 件の公式ふりがな（2026-09-13 採取）。

### 型番号 — 「がた」で確定（2026-09-13 ファウンダー確定）

348 件すべてで「型」は「がた」。「けい」と読むのは「非典型（ひてんけい）」のように
別の熟語の一部になっている場合だけで、病型の「型」に「けい」は 1 件も無い。

| 表記 | 読み | 表記 | 読み |
|---|---|---|---|
| I型 / 1型 | いちがた | VI型 / 6型 | ろくがた |
| II型 / 2型 | にがた | 7型 | なながた |
| III型 / 3型 | さんがた | 10型 | じゅうがた |
| IV型 / 4型 | よんがた | 11型 | じゅういちがた |
| V型 / 5型 | ごがた | 31型 | さんじゅういちがた |

4 と 7 は「し」「しち」を使わない。医療現場の慣行に合わせ「よん」「なな」。

**ローマ数字でも同じ**。小児慢性特定疾病情報センターのふりがなで直接確認できる。

```
糖原病Ⅰ型       → とうげんびょういちがた
ムコ多糖症Ⅰ型   → むこたとうしょういちがた
ムコ多糖症Ⅱ型   → むこたとうしょうにがた
ムコリピドーシスⅡ型 → むこりぴどーしすにがた
```

人名に付く「型」も「がた」。`デュシェンヌ（Duchenne）型筋ジストロフィー → でゅしぇんぬがたきんじすとろふぃー`。

**注意**: 難病情報センターの 348 件にローマ数字の型表記は 1 件も無く、すべて算用数字。
我々の知識ファイルは「ムコ多糖症I型」のようにローマ数字を 13 件使っており、公式の書き方とずれている。
読みは上の表で統一できるが、**表記そのものの統一は別の判断**（`docs/kb_issues_2026-08-29.md` に記録する候補）。

### 英字 — 一字ずつの英語読み

A=えー、B=びー、H=えいち、L=える、M=えむ、N=えぬ、R=あーる、U=ゆー、V=ぶい、X=えっくす。

```
IgA腎症            → あいじーえいじんしょう
ATR-X症候群        → えーてぃーあーるえっくすしょうこうぐん
LMNB1関連大脳白質脳症 → えるえむえぬびーわんかんれんだいのうはくしつのうしょう
脆弱X症候群        → ぜいじゃくえっくすしょうこうぐん
```

例外は、頭字語が単語として定着しているもの。公式 348 件では 3 件だけ。

```
VATER症候群              → ふぁーたーしょうこうぐん
乳児発症STING関連血管炎  → にゅうじはっしょうすてぃんぐかんれんけっかんえん
極長鎖アシル-CoA脱水素酵素欠損症 → ごくちょうさあしるこえー…
```

### 「分泌」は「ぶんぴ」

医学領域では「ぶんぴ」に統一する（日本内分泌学会。2026-09-13 ファウンダー確定）。
一般の読みである「ぶんぴつ」は使わない。

```
神経内分泌腫瘍             → しんけいないぶんぴしゅよう
成人成長ホルモン分泌不全症 → せいじんせいちょうほるもんぶんぴふぜんしょう
```

### ギリシャ文字の読み（2026-09-13 確定）

| 文字 | 読み | 根拠 |
|---|---|---|
| β | べーた | 難病情報センター 3 件・小児慢性 2 件が一致 |
| α | あるふぁ | 5α-還元酵素欠損症（小児慢性）の前例。α1 型の病名では公式が「あるふぁーわん」なので、その形は個別に当てる |
| γ | がんま | 出典なし。執筆者による読み |
| δ / Δ | でるた | 出典なし。執筆者による読み |

### 「頭蓋」は後続語で読みが変わる

**揃えてはいけない**（2026-09-13 ファウンダー確定）。脳神経外科領域で定着した使い分け。

| 語 | 読み |
|---|---|
| 頭蓋内圧 | **ずがい**ないあつ |
| 頭蓋骨 | **とうがい**こつ |

### ギリシャ文字

α=あるふぁー、β=べーた。長音符を付ける。

```
α1-アンチトリプシン欠乏症 → あるふぁーいちあんちとりぷしんけつぼうしょう
無βリポタンパク血症       → むべーたりぽたんぱくけっしょう
```

### 染色体の表記

染色体番号は数として読み、**帯番号は 1 桁ずつ**読む。ピリオドは「てん」。q は「きゅう」（「きゅー」ではない）。
出典: CMA 研究班の一般向け資料（http://square.umin.ac.jp/CMA/）。

```
16p11.2 → じゅうろくぴーいちいちてんに
15q13.3 → じゅうごきゅういちさんてんさん
8p23.1  → はちぴーにさんてんいち
22q11.2 → にじゅうにきゅういちいちてんに
4p      → よんぴー      5p → ごぴー
```

五十音の行は先頭の染色体番号で決まるので、帯番号の読み方は行に影響しない。

### 略号に付く数字 — 英語読み

ラテン文字の略号や記号に続く数字は、小児慢性特定疾病情報センターのふりがなでは**英語読み**。
病型の「◯型」（いちがた・にがた）とは扱いが違う。

```
GM1-ガングリオシドーシス    → じーえむわんがんぐりおしどーしす
GLUT1（グルコーストランスポーター1）→ …わんけっそんしょう
GRIN2B関連神経発達異常症    → じーあーるあいえぬつーびーかんれんしんけいはったついじょうしょう
α1-アンチトリプシン欠損症   → あるふぁーわんあんちとりぷしんけっそんしょう
```

**方針（2026-09-13 ファウンダー確定）**:

> 略号に含まれる数字は英語読み（小児慢性特定疾病情報センターの表記に準拠）。
> ただし難病情報センターが数字のまま表記している例もあるため、個別に出典が確認できる場合はそちらを優先する。

理由: 医師も患者も実際にそう発音する。「あいじーじーよん」と読む人はまずいない。

適用済み:

| 病名 | 採用した読み |
|---|---|
| IgG4関連疾患 | あいじーじーふぉーかんれんしっかん |
| MECP2重複症候群 | えむいーしーぴーつーちょうふくしょうこうぐん |

※ MECP2 の「重複」は、索引の公式ふりがなが「ちょうふく」。ファウンダー指示の文字列は「じゅうふく」だったが、
出典に忠実にという原則に従い「ちょうふく」を採った。要確認。

### 染色体番号・数字 — 公式は不統一。我々はかなに開く

難病情報センターのふりがなは数字を数字のまま残すことが多い（`あいじーじー４かんれんしっかん`）。
一部だけかなに開く（`いちぴー３６けっしつしょうこうぐん`、`ごぴー…`、`よんぴー…`）。全角と半角も混在している。

我々は並べ替えに使うため、**数字は必ずかなに開く**。頭文字がかなでないと行を決められないため。
公式の読みと違う形になったものは、readings.json の note に公式の読みを残す。

### 記号・括弧

**スラッシュ（/）・中黒（・）・ハイフン・括弧は読みに含めない**（2026-09-13 ファウンダー確定）。
読みに使ってよい文字は、ひらがなと長音符（ー）だけ。

主名の括弧内（型・限定・除外の指定）も読みに含めない。
読みは五十音の行と並び順にしか使わず、括弧の中は行にも並びにも効かないため。
主名と限定つきの主名（`原発性アルドステロン症` と `原発性アルドステロン症（両側型）` など）は
同じ読みになり、一覧で隣り合って並ぶ。探す側に都合がよい。

```
遺伝性褐色細胞腫/パラガングリオーマ症候群 → いでんせいかっしょくさいぼうしゅぱらがんぐりおーましょうこうぐん
3-メチルグルタコン酸尿症（Barth型以外）   → さんめちるぐるたこんさんにょうしょう
```


欧文人名・欧文略号の括弧も読みから外す（小児慢性の表記と同じ扱い）。

```
ゴーシェ（Gaucher）病 → ごーしぇびょう
ムコリピドーシスⅡ型（I-cell病） → むこりぴどーしすにがた
```

日本語の別名の括弧は、小児慢性では読みに含める（`フェニルケトン尿症（高フェニルアラニン血症）` →
`ふぇにるけとんにょうしょう　（こうふぇにるあらにんけっしょう）`）。
我々は主名の読みだけを持つので、この括弧部分は取らない。

`こふぃん・しりす…` → `こふぃんしりす…`。
読みに使ってよい文字は、ひらがなと長音符（ー）だけ。

### 「ヴ」— 語中は「ゔ」、語頭は「う」

**語中**はひらがなに「ゔ」をそのまま使う。元の表記に忠実で、検索でも一致しやすい。
例: フォン・ヴィレブランド病 → `ふぉんゔぃれぶらんどびょう`（は行。行は変わらない）

**語頭は「う」に畳む**（2026-09-14 ファウンダー確定）。
「ゔ」は清音に畳むと「う」なので あ行 に入るが、**あ行の末尾という誰も探さない場所**に飛ぶ。
患者が「ヴィーデマン」を あ行 で探すとは考えにくい。

例: Wiedemann-Steiner症候群 → `ういーでまんしゅたいなーしょうこうぐん`（あ行の「う」の位置）

## 並べ替え

`lib/portal/disease-list.ts` の `diseaseSortKey`。読みがあれば読み、無ければ病名のカタカナをひらがなに畳んだもの。
行の判定は頭文字を清音に畳む（じ→さ行、ぽ→は行、ふぁ→は行、ゔ→あ行）。

## 病名そのものが誤っている場合

読みを付ける前に病名を直す。読みだけ直しても、患者が探す行と違う場所に入る。
例: `Branchio-Oto-Renal症候群` は指定難病 190 の正式名が「鰓耳腎症候群」。
そのまま読むと は行だが、患者は「さいじじん」で さ行 を探す。
発見したものは `docs/disease_name_rename_2026-09-13.md` と `docs/kb_issues_2026-08-29.md` に記録する。
