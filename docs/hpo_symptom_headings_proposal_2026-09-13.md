表に無い理由で「その他」に落ちるものは現時点で 0 件（「声の異常」は 12 に入れた）。

順序の考え方:
- 検査所見を最初に取り出す（ファウンダー指示の機械的基準）。
- 臓器が特定できる下位カテゴリ（肝・脾・筋）を、上位カテゴリより先に当てる。脾腫は HPO 上「免疫系」だが患者には「脾臓」。
- 目・耳を神経より先に（眼球運動失行症 → 目）。神経を骨・関節より先に（下肢痙性・球麻痺 → 神経）。
- 頭・顔・口・歯を骨・関節より先に（大頭・頭蓋合骨症・歯の異常 → 頭・顔）。
- 成長をホルモンより先に（思春期遅発 → 成長・発育）。

## 4. 実装の置き場所（案）

- `scripts/hpo/build_hpo_categories.py`（新規）: `data/hpo/hp.obo` を読み取りのみで走査し、11 疾患の各 HPO ID について「上の表に出てくるカテゴリ ID のうち祖先にあるもの」を書き出す。
- `data/hpo_categories/hpo_categories_11.json`（新規、派生ファイル）: hpo_id → 祖先カテゴリ ID の一覧。`data/hpo_symptoms/` には触れない。アプリは hp.obo を読まない（今の方針どおり派生ファイルだけ読む）。
- `lib/portal/hpo-categories.ts`（新規）: 見出しの順序・日本語・条件・上書き表。純関数 `headingOf(hpoId)`。
- `lib/portal/diseases.ts`: `hpoSymptoms` に `heading` と `frequencyRank` を足す。
- `app/demo/diseases/[slug]/page.tsx`: 見出しごとの表示 + 「その他の報告されている症状（N件）」を `<details>` で折りたたみ。開いたら同じ見出し分けで残り全件。
- テスト: `lib/portal/__tests__/hpo-categories.test.ts`（ゴーシェ病の代表例が期待の見出しに落ちること、1 症状 1 見出し、全件が漏れなく出ること）。
