### 1 本の計画書・1 回の審査で複数の疾患を扱う（Claude Code の判断。審査委員会の判断を受ける）

## ③ 研究の目的及び意義

**目的**: 対象疾患（下の「対象疾患」）ごとに、患者が、最初の症状に気づいてから確定診断を受けるまでに、どの症状に気づき、どの診療科を受診し、いくつの医療機関・診療科を回り、どれくらいの期間がかかったかを、患者・家族の回答から記述的に集計する。

**意義**:
- 日本の先行調査（Tsurumi M, Ozaki A, Eto Y. *Mol Genet Metab Rep.* 2022;33:100909. PMC9411675）は、酵素補充療法中の 40 人を対象に、発症から確定診断まで平均 18.7 年（男性 16.7 年・女性 20.3 年）と報告している。一方で、同調査は製薬企業の依頼による 1 回きりの郵送調査で、対象が治療中の人に限られ、調査票は他の資料と照合されていない（同論文の本文による）
- 本研究は、治療の有無で対象を絞らず、患者会の会員エリアで継続的に回答を受け付け、会ごとの集計を会員自身が見られる形にする。早期の受診・紹介を考える材料を、患者・家族と医療者に疾患一般の情報として示す
- 本研究は回答者個人に対して、疾病の可能性の判定・助言・受診先の提示を行わない（医療機器プログラムにあたる機能を持たない）

## ④ 研究の方法及び期間

**方法**:
- 『となり』の会員エリアにある、対象疾患の患者会の会ごとのページに「病気がわかるまでの道のり」の回答フォームを置く（1 画面・選択式のみ・自由記述なし・14 問・約 3 分）。1 つの会が複数の病気を扱うときは、病気ごとに回答する
- 14 問は、全疾患で同じ**共通の 12 問**と、病気ごとに選択肢を変える**疾患別の 2 問**（最初に気づいた症状・家族の病歴が手がかりか）からなる（`docs/journey_survey_items.md` 改版 2026-10-04）
- 集計は**病気ごと・会ごと**に行い、病気をまたいで足し合わせない（⑧の秘匿も病気ごと・会ごとにかける）
- 設問と選択肢は `docs/journey_survey_items.md` のとおり（回答者・生まれた年〔5 年刻み〕・性別・地方〔8 区分〕・最初に気づいた症状〔複数選択〕・症状に気づいた年齢〔5 歳刻み〕・最初に受診した診療科・確定診断を受けた診療科・医療機関の数・診療科の数・確定診断を受けた年齢〔5 歳刻み〕・別の病名と言われた経験・家族歴が手がかりか・症状に気づいてから確定診断までの期間）。全設問必須だが、各設問に「答えない」「覚えていない」「わからない」のいずれかを置く（設問 1 の回答者を除く）
- 都道府県・暦年・日付・時刻は持たない。回答した月（月の 1 日）だけを持つ
- **解析**: 設問ごとの単純集計と、性別との 2 軸のクロス集計だけを行う。年齢や年数どうしの引き算（例: 確定診断までの年数の算出）は行わない。推測統計は行わない（Claude Code の判断。要否は研究責任者が決める）
- 集計は DB の関数（`journey_summary`）で行い、⑧の秘匿をかけた結果だけを画面に出す

**期間**: 倫理審査の承認後、研究機関の長の許可の日から **未定** まで（終了日は**未定**）

## ⑧ 個人情報等の取扱い

**持つ情報と持たない情報**:
- 回答の表（`journey_responses`）は会員の表と分け、**user_id（会員の識別子）を持たない**。氏名・表示名・メールアドレス・都道府県・日付・時刻も持たない
- 本人と回答を結ぶ**対応表**（`journey_links`）を別に置く。対応表は本人だけが自分の行を読める。本人の取り消しとアカウント削除のためだけに使い、**集計では一切使わない**
- 回答は、対応表を通せば個人を識別できる状態にある。このため本研究の回答は、仮名加工情報・匿名加工情報ではなく、**個人情報（要配慮個人情報）として扱う**（Claude Code の判断。審査で確認を受ける）

**技術的な保護**（DB で実装済み。`scripts/portal/verify_journey.sql` で確かめる）:
- 回答の表は、会員・未ログインのどちらからも直接は読めない・書けない（行の権限〔RLS〕を有効にし、許可を置かない）
- 回答・取り消し・自分の回答の確認・集計は、権限を固定した関数だけを通す
- 回答は外部の生成 AI（LLM）サービスへ送らない（運営の規則による）

**10 未満の秘匿**（集計関数 `journey_summary` で実装）:
- 人数が 10 未満のセルは数を出さず「10未満」と表示する（0 人も含む）
- 回答の総数が 10 未満のときは、集計そのものを出さない
- クロス集計は性別との 2 軸までとし、任意の掛け合わせは出さない
- **補完秘匿**（Claude Code の判断。2026-10-02 ファウンダー採用）: 伏せたセルを総数や他のセルとの引き算で戻せないよう、単一選択の設問で伏せたセルがちょうど 1 つの列では、次に小さいセルも伏せる。性別ごとの行は 1 つでも 10 未満なら 3 つとも伏せる。全体のセルを伏せた行は性別ごとのセルも伏せる
- **前月までの回答だけを数える**（Claude Code の判断。2026-10-02 ファウンダー採用）: 会員が、知人の回答の前後で集計を見比べて、その人の回答を割り出すことを難しくする
- **残るリスク**: 少人数の会では、集計の月ごとの差分から、その月に回答した少数の人の回答が推測されうる。生まれた年・性別・地方の組み合わせは集計では掛け合わせないが、DB の管理者は回答の行そのものを見られる（⑨）

**閲覧の範囲**:
- 会ごとの集計は、その会の会員なら誰でも見られる（世話人に限らない）
- 回答の行そのものを見られるのは、DB の管理者（運営者）だけ。研究者等が個票を扱うかどうか、扱う場合の手順は**未定**

## ⑨ 研究対象者に生じる負担並びに予測されるリスク及び利益

- **負担**: 約 3 分の回答。費用はかからない
- **リスク**:
  - 診断までのつらい経験を思い出すことによる心理的な負担（「答えない」「覚えていない」を各設問に置き、途中でやめられる）
  - 少人数の会での推測による、病歴の意図しない開示（⑧の秘匿で小さくする。完全には除けない）
  - DB への不正アクセスや管理者の誤操作による漏えい（回答の表に会員の識別子を持たせず、対応表を分けることで、回答の表だけが漏れた場合に個人と結びつかないようにする）
- **利益**: 回答者個人への直接の利益はない。集計は会員が見られ、疾患一般の情報として共有される
- **総合的評価**: 侵襲・介入を伴わず、負担は小さい。リスクは⑧の対策で小さくする（Claude Code の判断。評価は倫理審査委員会が行う）

## ⑩ 試料・情報等の保管及び廃棄の方法

- **保管場所**: 『となり』のデータベース（Supabase。PostgreSQL）
- **保存期間**: **未定**。指針は、侵襲・介入を伴わない研究について最低の保管期間を定めず、研究機関の長が可能な限り長期間の保管に努めるとしている（第13 ⑸）。運営方針「持ちすぎない」との兼ね合いを含め、審査で決める。回答した月（`answered_month`）を保存期間の起点に使える
- **取り消し**: 本人はいつでも、自分の回答のページ（`/demo/community/journey`）から回答を取り消せる。取り消すと回答と対応の行は DB から消える（物理削除）。ほかに回答が残っていなければ、調査への同意も取り消される（同意の記録の行は残り、取り消した時刻が入る）。取り消す前に公表した集計からは取り除けない
- **アカウント削除・会の退会**: アカウントを削除すると回答と対応も消える。会を退会しても回答は消えない（取り消しは会をまたいで行える）。運営者が会員の登録（auth.users）を直接消した場合も、対応が消えるのに合わせて回答も消える
- **バックアップ**: DB のバックアップに、削除前の回答がどれだけの期間残るかは**不明**（契約しているプランのバックアップ保持期間を確かめる）
- **廃棄**: 保存期間の終了後に回答の表を削除する手順は**未定**
