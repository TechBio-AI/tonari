# となり

「となり」は、希少疾患・難病とともに生きる人と家族のための情報ポータルです。
病気は違っても、困りごとは似ている。そんな人どうしが、疾患をこえて集まれる場所を目指しています。

- 日本の指定難病・小児慢性特定疾病などを起点に、病気ごとの一般的な情報を、出典を示して載せています
- 個人の状態を判断したり、受診先をすすめたりはしません。病気一般の情報を、出典とともに伝えます
- 患者会の一覧と、患者会ごとの会員エリア（お知らせ・スレッド・行事など）があります
- 難病相談支援センター・難病診療連携拠点病院の一覧があります
- 医療に関する判断は、必ず主治医にご相談ください

**このリポジトリはプロダクトデモ用の写しです。** 会員エリアの投稿・会員などは、すべて架空の見本データです。

## 動かし方

Node.js 22 が要ります。

```
npm ci
npm run dev
```

ブラウザで http://localhost:3000/demo を開きます。

ログイン・会員エリアなど Supabase を使う画面を動かすには、次の環境変数が要ります（`.env.local` に書く。値はこのリポジトリには含めていません）。

- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `NEXT_PUBLIC_SITE_URL`

データベースの定義は `supabase/migrations/` にあります。デモ用の見本データは `supabase/seed_demo_cloud_fabry.sql` です。

テストは `npm test`、公開面の表現の検査は `bash scripts/lint-wording.sh` で動きます。

データの出典は `NOTICE.md` を参照してください。
